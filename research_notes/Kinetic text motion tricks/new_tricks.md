# New Tricks and Trends in Motion Design and Kinetic Text 2025-2026

## What AI or generative workflows for motion/kinetic text are designers actually using in 2025-2026?

### Takeaway
Designers in 2025-2026 use Runway Gen-4.5 / Aleph / Act-Two, Pika 2.2 Pikaframes/Pikascenes/Pikaswaps/Pikaffects, HeyGen kinetic captions, AE AI Assistant for auto-sync, and data-driven Cavalry as accelerators — but the reliable kinetic-text workflow is still camera/lighting/B-roll in AI + real text in post, because text-to-video still warps letters and breaks physics/speed continuity.

### Cited Findings
- Runway Gen-4.5 launched Dec 1, 2025 as text-to-video, #1 on Artificial Analysis Text-to-Video with 1,247 Elo, claiming unprecedented physical accuracy, weight/momentum, coherent hair/material weave, stylistic control from photoreal to stylized animation, plus Image-to-Video, Keyframes, Video-to-Video modes — [Source](https://runway.com/research/introducing-runway-gen-4.5)
- Runway timeline 2025: Gen-4 March 31 with reference consistency, Aleph July 25-31 as in-context instruction-based video editing (change objects, viewpoint, lighting, style), Act-Two July 17-21 performance-driven full body/head/face/hand animation, Gen-4.5 Dec 4 — [Source](https://www.scriptbyai.com/runway-ai-timeline)
- Runway Act-Two extends Act-One facial driving to full-body motion tracking without markers, 30s clips, controls for aspect, expressiveness, gesture — [Source](https://www.artofsm.art/t/runway-act-2-is-here-full-body-motion-tracking/11169)
- Pika 2.2 (Feb 2025) offers 720p-1080p, up to 10s, Pikaframes keyframe interpolation (start/end images, 1-10s per transition, up to 5 keyframes / 25s total), Pikascenes multi-image scene builder with exact character/object/wardrobe/setting, Pikadditions adding generated image to existing video, Pikaswaps swapping element in existing video — [Source](https://wavespeed.ai/blog/posts/introducing-pika-v2-2-pikaframes-on-wavespeedai); [Source](https://ai.unext-hd.co.jp/all/pika-ai-latest-update-2025)

## What interactive/web tricks (scroll triggers, mouse physics, text to video) are trending?

### Takeaway
The shippable web stack in 2025-2026 is CSS `animation-timeline: scroll()` as baseline + GSAP ScrollTrigger + SplitText (now free) for choreography, plus Matter.js mouse physics, cursor repulsion, and Rive state machines for runtime-editable text — all documented with copy-paste demos.

### Cited Findings
- Chrome 115 (Aug 2023) shipped CSS scroll-driven animations, now across all major browsers; CSS scroll-driven offloads to compositor, costs ~0 JS, survives mobile better than RAF JS — [Source](https://www.3str.net/blog/kinetic-typography-in-web-design)
- GSAP 3.13 (Apr 29, 2025): all plugins now 100% FREE on public NPM, SplitText rewritten with Screen-reader aria-labels, responsive re-splitting, slice through nested <span>/<strong>/<a>, propIndex --word variables, autoSplit + onSplit to avoid font-load jank — [Source](https://gsap.com/blog/3-13/)
- GSAP SplitText + ScrollTrigger Caveat (Aug 7-8, 2025 forum): wait for `document.fonts` / autoSplit, else custom fonts loaded from CDN throw off calculations — [Source](https://gsap.com/community/forums/topic/44907-improving-reliability-and-performance-of-splittext-elements-and-scrubbed-timeline-animation)
- NRK case study (Feb 26, 2025): scroll-driven title "Sjukt/sjuke" animated with `animation: fade-up linear; animation-timeline: view(); animation-range: entry 100% exit 100%` for scrollytelling, off-main-thread vs janky JS — [Source](https://developer.chrome.com/blog/nrk-casestudy)
- Studio Meyer 2026 Guide: split types Line/Word/Char, 30-50ms stagger fluid vs 100ms+ dramatic, limit to 2-3 split elements/page (50 chars = 50 spans = mobile jank), only animate transform+opacity (GPU), respect prefers-reduced-motion, subset variable fonts via glyphanger/pyftsubset — [Source](https://studiomeyer.io/en/blog/kinetische-typografie.md)
- Codrops Nov 4, 2025 demo — 3D scroll effects with CSS+GSAP no Three.js: Cylinder `perspective:70vw; transform-style:preserve-3d; translate3d+rotateX` + `ScrollTrigger pin scrub:2 rotateX -80→270 over +=2000svh`, Double Circle mirrored `direction:1/-1` with `rotate+180` fix for right side readability, Tube `rotateY 0→360` tunnel; GitHub + 3 live demos — [Source](https://tympanus.net/codrops/2025/11/04/creating-3d-scroll-driven-text-animations-with-css-and-gsap/)
- Codrops Oct 13, 2026 scroll-driven ghost trails: rippling letters + outlined copies via Canvas2D+GSAP+Three.js; Oct 26, 2026 "Animating with Agents: Building a Kinetic Type Site with GSAP and Animaxxing Skills" — [Source](https://tympanus.net/codrops/2026/10/13/scroll-driven-ghost-trails/); [Source](https://tympanus.net/codrops/2026/10/26/animating-agents-gsap-animaxxing/)
- Mouse physics standard: Fancy Components Gravity — Matter.js world with 4 walls, `MouseConstraint stiffness:0.1 damping:0.15`, pills rain/pile/ fling, keep upright via angle clamp, DOM stays crisp — [Source](https://www.fancycomponents.dev/docs/components/physics/gravity)
- Cursor micro-interactions showcase (2026): 1 Magnetic Buttons spring pull, 2 Canvas particle trail, 3 Text Repulsion chars push from cursor, 4 Image Distortion ripple, 5 Ripple Click, 6 Drag physics throw bounce, 7 Elastic Scroll, 8 Spotlight Gallery — [Source](https://github.com/KaranChandekar/cursor-micro-interactions)
- Variable Font + Mouse: GSAP Forum + CodePen pattern `gsap.to('.char', {'--wght':900, stagger:{yoyo:true,each:0.2}})` with Splitting.js; GSAP to CSS var --wght with font-variation-settings 'wght'; quickTo for mousemove — [Source](https://codepen.io/samvgm/pen/PoZGeVB); [Source](https://gsap.com/community/forums/topic/32561-animate-variable-font-on-mouse-move)
- Rive 2025 Text: Jan changelog — enable animation of text run style property; Apr 9 Text Follow Path (align text along shape, bind to data); runtime text via Data Binding (change color/size/text/images/lists at runtime, auto-layout reflow) vs Lottie requires vector convert, no runtime text; Duolingo 15x smaller, Spotify Wrapped final animation built in Rive, Dropbox brand site in Rive, Wix Studio integration — [Source](https://community.rive.app/c/announcements/text-follow-path-release); [Source](https://rive.app/blog/rive-as-a-lottie-alternative); [Source](https://rive.app/blog/press)
- Rive accessibility trend: DOM-live animations allow dynamic color/speed, layout background fits text, timeline playback 0x for user control to hit WCAG AAA Animation from Interactions, keep 60fps, ≤3 flashes/sec — [Source](https://rive.app/blog/making-rive-designs-more-visually-accessible)
- Scroll + 3D production pattern 2026: CSS `@supports (animation-timeline:scroll()){ animation-timeline:scroll(root); animation-range:entry 0% entry 40% }` as progressive enhancement, GSAP for complex scrub/pin timelines, video/GIF only last resort for fixed resolution — [Source](https://www.3str.net/blog/kinetic-typography-in-web-design)
- TouchDesigner live reactive text 2025: Oct 9, 2025 AudioReactive Text with Tracing and Instancing tutorial — instancing geometry from text structure + Audio Analysis CHOP mapping to network — [Source](https://derivative.ca/community-post/tutorial/audioreactive-text-tracing-and-instancing-touchdesigner-tutorial/73009)

## What 3D/2.5D and shader text effects are newly popular?

### Takeaway
Faux-3D CSS cylinders/tubes, Cavalry 2.5 Spherise + 2.6 deformers, After Effects Variable Font Animators, and WebGPU/TSL MSDF text dissolve/destruction are the hot 3D/shader text effects of 2025-2026 — all demonstrated with shaders, not 3D model imports.

### Cited Findings
- Cavalry 2.5 Spherise Filter: map input Shape onto sphere, rotate, visibility inside sphere, lighting/shadow/bump — faux 3D — [Source](https://medium.com/cavalry-animation/whats-new-in-cavalry-2-5-70441e6b3703); Cavalry 2.6 beta (Dec 8, 2025): new deformers for text/texture, Wave Deformer applied to letters in Instagram demos, Forge Dynamics + wave combos — [Source](https://schoolofmotion.com/blog/motion-mondays-december-8-2025); [Source](https://www.instagram.com/p/DScCB5rDXGd)
- After Effects Beta 26.0x40 (Nov 20, 2025): Variable Font Animation support — stretch/squash/jitter/transform via Text Animators + variable axes, solves "old hacks" — [Source](https://community.adobe.com/announcements-532/introducing-variable-font-animation-in-after-effects-beta-26-0x40-314512)
- Three.js + GLSL interactive letter displacement (Mar 24, 2025): Orthographic camera, raycast hit point → vertex shader `dist = length(uDisplacement - worldPosition.rgb)`, radius 3., `distance_mapped = map(dist,0.,min,1.,0.) * easeInOutCubic *1.` displace Z, increase PlaneGeometry segments for smoothness, second plane for illumination/shadow blur for pseudo-3D — [Source](https://tympanus.net/codrops/2025/03/24/animating-letters-with-shaders-interactive-text-effect-with-three-js-glsl)
- WebGPU Gommage (Jan 28, 2026): Three.js WebGPU MSDF text dissolves via noise-driven TSL shader + dust InstancedMesh + spinning petal particles (bend+spin) + selective bloom via MRT; atlas+JSON+shader, packed Birth/Life/Seed/Scale instanced attribute to avoid WebGPU limits — [Source](https://tympanus.net/codrops/2026/01/28/webgpu-gommage-effect-dissolving-msdf-text-into-dust-and-petals-with-three-js-tsl/)
- Interactive Text Destruction (Jul 22, 2025): Three.js + WebGPU + TSL letters explode into dynamic shapes; Interactive deconstruction, organic distortion infinite scroll (Nov 6, 2024 → 2025 reuse); 3D Circle Text with msdf-text-utils Feb 3, 2025 — [Source](https://tympanus.net/codrops/tag/typography)
- VFX-JS Text Effects (Jan 20, 2025): WebGL text without 3D geometry — convert `<span>/<h1>` via SVG `foreignObject` → canvas → WebGL texture; `vfx.add(el,{shader:"glitch"})` or custom GLSL; pixelation `uv.x = floor(uv.x*10.)/10.`; mouse velocity uniform `posDelay mix(posDelay,pos,0.05) → velocity` for RGB shift; note experimental, limits deeply nested — [Source](https://tympanus.net/codrops/2025/01/20/vfx-js-webgl-effects-made-easy)
- Responsive SEO-friendly WebGL Text guide (Jun 5, 2025): combine responsive HTML text with WebGL rendering for scroll-driven + custom shader effects — [Source](https://tympanus.net/codrops/2025/06/05/responsive-webgl-text/)
- High-fidelity 3D font rendering (Nov 2, 2025): `three-text` Slug algorithm, one quad per glyph, winding number coverage, sharp at any zoom, per-glyph attributes `glyphIndex/glyphCenter/time` for shader injection `outPos.y += sin(glyphIndex*0.5+time)*waveAmplitude` — [Source](https://github.com/countertype/three-text)
- CSS 3D illusion recipe (Codrops 2025) repeats as trend: `perspective:70vw; transform-style:preserve-3d; backface-visibility:hidden` for cylinder/tube without WebGL, used on BPCO/Sturdy agency sites — [Source](https://tympanus.net/codrops/2025/11/04/creating-3d-scroll-driven-text-animations-with-css-and-gsap/)
- TouchDesigner audio-reactive 3D text (2025): Text TOP → SOP circle → Creep SOP curved text → Render TOP, Letter-by-Letter template, feedback loop video text; audioAnalysis + instancing scale drive geometry — [Source](https://github.com/LucieMrc/TD_textEffects)
- Motion trend aesthetic: vibrant gradients/metallic shifts as text moves, neon/high-contrast for impact, morphing letters stretching/twisting in place — [Source](https://www.illustration.app/blog/kinetic-typography-in-practice-designing-text-that-moves-with-purpose)

### Inferences
- Shader text is now a two-lane scene: (1) Lightweight faux-3D (CSS/Cavalry) for marketing/landing — fast, accessible, printable. (2) Heavy WebGPU/TSL MSDF+particles for hero moments — dissolve, explosion, displacement; requires atlas workflow (png+json) + InstancedMesh particles + bloom.
- Cavalry Spherise + Variable Font Animators are the most direct drop-in for AE/C4D designers who want 3D-look 2D without Three.js.
- VFX-JS foreignObject trick is the fastest prototype for shader text on DOM — 1 line `npm i @vfx-js/core` + GLSL uniform velocity/time — ideal for R&D before committing to Three/MSDF pipeline.
